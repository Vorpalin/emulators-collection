# ROM storage and usage policy

Emulators Collection does not provide, distribute, or host game ROM files.

When a user imports a ROM, the file is stored in that user's browser using IndexedDB. The ROM binary is not uploaded to Supabase or sent to the project backend. Supabase stores account information and game-library metadata only.

Browser storage is local to the browser profile and origin. ROM files do not automatically follow a user to another browser or device, and may be removed if the user clears site data or the browser evicts storage. Users should keep their own backups.

Users are responsible for ensuring that they have the legal right to possess and use every ROM they import. The application does not grant rights to copyrighted games or firmware.
